# Imported from hifi-remote.com's Sony code pages

Everything under `remotes/hifi-remote/` except this file is generated by
`rl import hifi-remote` from the snapshot in `sources/hifi-remote/`. It is
**not authored here**. SPEC.md R19 sets the conditions an import must meet,
and DESIGN.md section 27 describes how this one meets them.

- **Upstream:** <https://www.hifi-remote.com/sony/>, "Rhm5757's Sony Code
  Page": one person's compilation of Sony's infrared command numbers, "most
  of the information from [Pronto or One For All] remotes", one page per kind
  of device. It is a hobbyist's reference table, not a Sony publication.
- **The pin:** the site is not a git repository, so the pin is a snapshot.
  `sources/hifi-remote/` holds every page as the server sent it, and its
  `MANIFEST.json` the retrieval date, each page's SHA-256 and the server's
  `Last-Modified` and `ETag`. `tools/fetch_hifi_remote.py` makes it. The
  importer refuses a page whose hash differs, and every citation names the
  first eight hex digits of its page's hash.
- **Licence:** none recorded. A table saying which command number a device
  code answers to is a set of facts about Sony's remote protocol, and the
  repository treats it so (DESIGN D110). The citations name the page and the
  row, so the source stays visible.

## What it imports

Each page is a few tables of `Command Code | Command(s)`, and above each table
a line `Sony:<device codes>` says which device codes the table is for. Every
table becomes one file per device code on its line, and every row a key. The
files hold no remote model, because the pages have none: a model is the kind
of device and the device code (`Blu-ray 26.226`, `Receiver 16`), and `controls`
says the same in a sentence. Everything is Plausible, one source, and a row the
page itself marks as doubtful ("probably incorrect") is Untested.

A device code is read as Sony's infrared frame it names: the 12-bit frame
(`Sony12`) below 32, the 15-bit frame (`Sony15`) from 32 up, and a dotted code
(`26.226`) as the 20-bit frame (`Sony20`) with a subdevice, unless the page
says otherwise (`Sony15:26`, `Sony20:1.0`). A colour on a command is the
page's own annotation. Its legend is in each citation, and where a legend
limits a command to one device code (the Blu-ray page's portable player and
home entertainment server) the command is left out of the others' files.

`IMPORT.md` lists everything the snapshot holds that does not become a file,
with the reason.
