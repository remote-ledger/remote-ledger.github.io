Notes

1 All device sources can be selected by index 0 to N. There is a 1s timeout to allow for multiple digits (for devices with more than 10 sources). Use the * command to initiate direct source selection (e.g. send * 1 3 to select source 13).
2 Audio check can oly be activated if device is in standby and disconnected from the network on power on
3 Programmable source will be set to the currently active source. Device must be out of standby.
4 Toggle lipsync enable/disable will only work for sources that support delay modes.

Use software like MAKEHEX to convert these into HEX codes used by PRONTO remotes
A sample of MAKEHEX code for the Linn DS/DSM can be found HERE

Discrete source selections on Linn DSM Products

The Linn DSM products have six discrete codes for external inputs or PINS.

PIN1 Addrs: 0x10 cmd: 0x77
PIN2 Addrs: 0x10 cmd: 0x78
PIN3 Addrs: 0x10 cmd: 0x79
PIN4 Addrs: 0x10 cmd: 0x7a
PIN5 Addrs: 0x10 cmd: 0x7b
PIN6 Addrs: 0x10 cmd: 0x7c
