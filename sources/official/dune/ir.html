Remote Control

Types of Dune HD Remotes

There are the following types of Dune HD Remotes:

  • Google-certified Bluetooth remotes -- shipped with Google-certified (ATV) Dune HD media player models:
    • BOXY Remote -- shipped with BOXY model.
    • Homatics Remote -- shipped with some first batches of Homatics Box 4K Plus model.
    • Homatics Big Remote -- shipped with later batches of Homatics Box 4K Plus model and other models.
  • Dune HD Bluetooth remotes:
    • DuneHD RC X2001 (Dune HD BT AirMouse Remote) -- shipped with various 2018+ models. AirMouse. 20 buttons.
    • Dune Remote R0 -- shipped with various 2020+ models. Microphone + AirMouse. 20 buttons.
    • Dune Remote R1 -- shipped with various 2021+ models. Microphone + IR learning + IR mode. 37 buttons.
    • Dune Remote R3 -- shipped with various 2021+ models. Microphone + IR learning + AirMouse. 43 buttons.
  • Dune HD IR remotes:
    • IR Remote (CFCF) -- shipped with various 2018+ models.
    • Slim IR Remote (CFCF) -- shipped with various 2018+ models.
    • Simple IR Remote (CFCF) -- shipped with various 2018+ models.
    • Premium IR Remote (00BF) -- shipped with Dune HD Duo 4K and various 2018+ models.
  • Discontinued models of Dune HD IR remotes:
    • Legacy Slim Remote (00BF) -- shipped with Dune HD TV-102 and other latest models.
    • Legacy New Small Remote (00BF) -- shipped with Dune HD TV-101/301.
    • Legacy New Big Remote v2 (00BF) -- shipped with Dune HD Smart D1/H1/B1, Dune HD Max, Dune HD Duo, Dune HD Lite 53D.
    • Legacy New Big Remote v1 (00BF) -- shipped with Dune HD Base 2.0, Dune HD Prime/Base 3.0, Dune HD Smart D1/H1/B1, Dune HD Max, Dune HD Duo, Dune HD Lite 53D.
    • Legacy Old Big Remote Black (01BE) -- shipped with Dune BD Prime, Dune HD Center, Dune HD Base, Dune HD Mini.
    • Legacy Old Big Remote Silver (01BE) -- shipped with Dune HD Ultra and Dune HD Mini.

Google-certified Bluetooth remotes

  • Features: Microphone + programmable buttons + IR mode.
  • Factory state: the remote is unpaired and can control the media player via IR.
  • Key combinations:
    • "HOME" + "BACK" 3 sec: enter pairing mode.
  • Programmable buttons: some buttons (V+/V-/MUTE, POWER, TV INPUT) can be configured to send IR signals to control the TV or A/V receiver or soundbar. To configure these programmable buttons: ensure the remote is paired to a Google-certified media player, and use Android settings menu ("Set up remote buttons") in this Google-certified media player. Follow the on-screen instructions shown on TV screen.
  • IR codes: Google IR codes.
  • IR mode: the remote automatically switches into IR mode when it is unpaired or not connected to the media player.
  • How to learn IR codes from this remote into a 3-party learnable remote: just disconnect power from the media player to which this remote is paired. The remote will automatically switch into IR mode. The remote will return to Bluetooth mode after you switch the media player on.

Dune HD Bluetooth remotes

DuneHD RC X2001:

  • Features: AirMouse. 20 buttons.
  • Factory state: the remote is unpaired.
  • Key combinations:
    • "ENTER" + "RETURN" 3 sec: enter pairing mode.

Dune Remote R0:

  • Features: Microphone + AirMouse. 20 buttons.
  • Factory state: the remote is unpaired and is ready for auto pairing (press any key to start auto pairing procedure).
  • Auto pairing procedure: when the remote is ready for auto pairing: direct the remote to the media player and press any key on the remote. The remote will enter the pairing mode and will send a special IR signal which will request the media player to automatically pair the remote.
  • Key combinations:
    • "POP UP MENU" 2 sec: microphone / search function.
    • "ENTER" + "V+" 3 sec: enter pairing mode ("ENTER" + "RETURN" 3 sec does the same).
    • "ENTER" + "V-" 3 sec: unpair, enter "ready for auto pairing" mode.
    • "ENTER" + "TOP MENU" 3 sec: reset to factory defaults.

Dune Remote R1:

  • Features: Microphone + IR learning + IR mode. 37 buttons.
  • Factory state: the remote is unpaired and is ready for auto pairing (press any key to start auto pairing procedure). "TV POWER" key is programmed to control LG TV. Other learnable keys ("V+", "V-", "MUTE") are set to control the media player.
  • Auto pairing procedure: when the remote is ready for auto pairing: direct the remote to the media player and press any key on the remote. The remote will enter the pairing mode and will send a special IR signal which will request the media player to automatically pair the remote.
  • Key combinations:
    • "ENTER" + "V+" 3 sec: enter pairing mode.
    • "ENTER" + "V-" 3 sec: unpair, enter IR mode.
    • "ENTER" + "TOP MENU" 3 sec: reset to factory defaults.
    • "TOP MENU" + "UP" 3 sec: program one key: press learnable key ("V+", "V-", "MUTE", "TV POWER"), press key on another remote.
    • "TOP MENU" + "DOWN" 3 sec: reset learned key to default function: press learned key ("V+", "V-", "MUTE", "TV POWER").
    • "RETURN" + "UP" 3 sec: toggle volume keys ("V+", "V-", "MUTE") between controlling the media player and controlling the TV.

Dune Remote R3:

  • Features: Microphone + IR learning + AirMouse. 43 buttons.
  • Factory state: the remote is unpaired and is ready for auto pairing (press any key to start auto pairing procedure). Learnable keys (in "TV" section) are programmed to control LG TV.
  • Auto pairing procedure: when the remote is ready for auto pairing: direct the remote to the media player and press any key on the remote. The remote will enter the pairing mode and will send a special IR signal which will request the media player to automatically pair the remote.
  • Key combinations:
    • "ENTER" + "V+" 3 sec: enter pairing mode.
    • "ENTER" + "V-" 3 sec: unpair, enter "ready for auto pairing" mode.
    • "ENTER" + "TOP MENU" 3 sec: reset to factory defaults.
    • "TV DOWN" + "TV UP" 3 sec: program the keys: press learnable key (in "TV" section), press key on another remote, repeat for other learnable keys if needed.

Troubleshooting for Bluetooth remotes

  • If the media player has external Wi-Fi/Bluetooth antennas: ensure antennas are properly attached to the media player.
  • Ensure the batteries are installed into the remote.
  • Ensure the batteries in the remote are fresh.
  • For the best operation of the remote, it is recommended to use alkaline batteries.
  • In case of problems, try to repair the remote to the media player from the scratch: unpair (delete) the remote in media player settings; reset the settings of the remote by pressing "ENTER" + "TOP MENU" remote buttons for 3 seconds (if the remote support this key combination), then pair the remote to the media player again.
  • If nothing else helps: try to reset settings of the media player too.
  • When you unpair the remote from the media player (or when you pair it to another device): also unpair (delete) this remote in the media player settings.
  • When you reset settings of the media player: also reset settings of the remote or unpair the remote (if the remote has key combinations for settings reset or unpairing).

Google-certified Bluetooth remotes and Google-certified Dune HD media players with built-in IR receiver use Google IR codes (Dune HD IR codes are not supported).

Dune HD IR codes

Other Dune HD IR Remotes and Non-ATV Dune HD media layer models use NEC IR protocol with custom Dune HD IR codes. Different generations of Dune HD IR Remotes use different NEC IR customer codes:

  • Current generation (shipped with 2018+ models, except Premium IR Remote): CF CF
  • Previous generation (Premium IR Remote + discontinued models): 00 BF

NOTE: All firmware versions of all non-ATV Dune HD models support the customer code "00 BF". The customer code "CF CF" is supported by latest Dune HD models, and is partially supported by latest FW updates for previous Dune HD models (excepting that "hardware standby" mode on these Dune HD models still requires the use of the customer code "00 BF").

Notes about support for very old legacy Remote models in very old legacy Dune HD models:

  • Old Remotes are supported by all Dune HD models. New Remote v1 is supported by all Dune HD models starting with Dune HD Base 2.0. New Remote v2 and Small New Remote are supported by all Dune HD models staring with Dune HD Base/Prime 3.0 (old models require the latest firmware).
  • Both kinds of Old Remote (Silver and Black versions) have overlapping IR codes -- the IR codes as the same for most buttons, but some buttons have different IR codes on Silver and Black versions of Old Remote; the setting "Setup / Misc / Advanced / Remote control kind" allows to specify the exact kind of Old Remote.

Full Power Off Using Remote (some models)

Full Power Off Using Remote is supported for many models starting with Dune HD Base 2.0. These player models have a special setting (Setup / Misc / Power Management / "POWER" button behavior) allowing to specify whether the "POWER" remote button should trigger "software standby" or "power off" (hardware standby).

It is also possible to perform an emergency "full power off" by pressing and holding the "POWER" remote button for a few seconds (supported only for models with special power management microcontroller), but this special possibility is not recommended for the regular usage (since this is handled purely by the hardware, and the player can not shutdown properly, such as properly writing all changes to connected HDDs).

Discrete Power On/Off IR Codes (some models)

Starting with the firmware version 091229_1411_beta, all Dune HD player models (except Google-certified ATV models) have support for DISCRETE-POWER-ON and DISCRETE-POWER-OFF IR commands. These IR commands can not be generated using any Dune HD Remote, and are intended only for users of programmable remotes.

IR HEX codes for DISCRETE-POWER-ON and DISCRETE-POWER-OFF commands (NEC protocol, customer code 00 BF): 

    DISCRETE-POWER-ON       00 BF 5F A0
    DISCRETE-POWER-OFF      00 BF 5E A1

The player handles these DISCRETE-POWER-ON and DISCRETE-POWER-OFF IR commands exactly the same way as the standard POWER IR command (generated by the "POWER" RC button on the standard Dune remote), with the only difference that DISCRETE-POWER-ON is ignored if the player is already switched on, and DISCRETE-POWER-OFF is ignored if the player is already switched off.

Notes on DISCRETE-POWER-ON IR command and standby modes in various Dune HD models:

  • Dune HD models based on RTD1619 media processor (such as Dune HD Pro 4K II) support DISCRETE-POWER-ON IR command only when "Setup / Misc / Power management / POWER button behavior" setting is set to "Software standby" (as of 2020-08-01; support for "Power off" mode will be provided in a future software update).
  • Other Dune HD models starting with Dune HD Base 2.0 support DISCRETE-POWER-ON IR command in all standby modes (including "Software standby" and "Power off").
  • Very old Dune HD models (prior to Dune HD Base 2.0) support DISCRETE-POWER-ON IR command only when "Setup / Misc / Power management / POWER button behavior" setting is set to "Software standby".

Forcing power-off (some models)

Some Dune HD models starting with Dune HD Smart/Max/Duo can be forced to perform full power-off by pressing and holding POWER RC button for a few seconds; in this case, the power-off is forced by the hardware and the software has no chance to handle it (e.g. write unchanged data to disks etc), so it should be used carefully (e.g. when the player hangs up). The recommended way to put the player into full power-off mode is to configure POWER RC button to do full power-off. The following approach can also be used: if POWER RC button is configured to enter software standby, the following alternative approach can be used: first press POWER RC button and wait for the player to enter standby mode; then press and hold POWER RC button for 2-3 seconds, and then release it -- this will trigger full power-off with proper software handling.

Automatic power-on mode (some models)

Some Dune HD models starting with Dune HD Smart/Max/Duo do not boot automatically when the power is connected. Instead they are put by default into hardware standby mode, and wait for the user to explicitly request power-on.

Some Dune HD media players which have a special power management microcontroller (such as Dune HD Smart D1/B1/H1 with serial number on the unit ASD1LHVAA***1123***00001 or greater, Dune HD Lite 53D, Dune HD TV-101/301) can be reprogrammed to boot automatically on power-on. Reprogramming affects the flash memory of the microcontroller which is responsible for power on/off handling, and can be done in the following way: 

- Put the unit into hardware standby (full power-off) mode.
- Carefully direct the RC onto the IR eye.
- Carefully press the following sequence of RC buttons:
    P, O, W, E, R, 1, ENTER
- The unit should LED-blink once. If the unit does not blink, try again
  several times. If it does not work, it means the unit has an old version
  of the MCU firmware and auto-power-on mode is not supported by the unit.
- To disable auto-power-on: the same, but press:
    P, O, W, E, R, 0, ENTER
