Sony DVD/Receiver, HTIB, Dream System (80, 208, 16.16)

 

I have merged the Dream System page into this page since the new Dream Systems use these codes.  Devices using these codes include the new DVD/Receiver combos, which are frequently sold as “Home Theater in a Box” (HTIB) systems by including speakers, as well as the Dream System packages.  The remote for these says AV System 3, so this may be a continuation of the receiver codes, but there are a lot of new things for DVD control and the like.  The older Dream System models uses some of these as well as some AV1 receiver codes and some DVD codes.  The current trend seems to move a lot of commands to 16.16 rather than other devices, so some functions are listed more than once due to this change.
