# Brands the `selected` bundle carries, in priority order (DESIGN.md D92).
#
# One brand per line, as the catalog spells it or any spelling with the same
# search key (case, spaces and punctuation do not matter: `Harman-Kardon` is
# `HARMAN KARDON`). Text after a `#` is a comment: the categories a brand is on
# the list for.
#
# THE ORDER IS THE PRIORITY. The bundle takes the brands from the top and
# carries each whole (all its models, remotes and signals) when what it adds
# still fits the size budget of `bundle/select.py`; a brand that does not fit is
# skipped, the next one is tried, and `rl bundle --profile selected` says which
# brands of this list were left out. So the owner changes what ships by moving a
# line, or by adding one, and the budget does the rest.
#
# This list is the owner's to review and edit. The ledger has no popularity data:
# it is a judgement of which consumer-electronics brands a person with a TV, AV
# receiver, set-top box, streaming box, projector, soundbar or disc player is most
# likely to own, checked against what the catalog holds. Air conditioners are out
# of scope. Every line that matches no brand of the catalog is printed, so a typo
# or a brand the catalog does not have shows up.
#
# Not in the catalog today, so not listed (a line for them would match nothing):
# Amazon (Fire TV), Google (Chromecast), Dish, Virgin Media, Polk, Nintendo.
